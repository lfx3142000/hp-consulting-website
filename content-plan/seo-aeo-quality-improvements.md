# SEO/AEO Quality Improvements Beyond More Pages

## Purpose

This file captures SEO and AEO improvements that do not depend on creating more pages. These should be applied to existing pages and future pages to make the site more useful, more structured, more credible, and more answer-engine friendly.

The current strategy is to let the site simmer: improve quality now, get pages indexed, gather Search Console data, and delay active consulting operations until there is evidence of demand.

## Core idea

Do not rely only on new pages. A smaller set of high-quality pages with direct answers, source panels, practical checklists, comparison tables, diagrams, template previews, and internal links will likely perform better than many thin pages.

## Quality improvements to apply

### 1. Source-backed direct answer blocks

Add a direct answer block near the top of important pages.

Suggested format:

```text
## Direct answer
[2-4 sentence answer.]

Applies to: [NRC, Agreement States, MA, CT, ME, NH, RI, VT, medical use, industrial, research, etc.]
Verify against: [10 CFR part, state regulation, license condition, regulator guidance.]
Common mistake: [one practical pitfall.]
```

### 2. Regulatory source panels

Add a compact source panel to technical pages.

Possible fields:

- Federal baseline.
- State rule.
- License-specific check.
- Program-specific check.
- Last updated date.

### 3. Common inspection findings and mistakes

Add practical examples that differentiate the site from generic regulation summaries.

Examples:

- Package receipt record missing label category, transport index, or 1-meter reading.
- Survey meter calibration current, but source checks are not documented.
- Procedure frequency does not match actual records.
- Training roster exists, but site-specific training is not documented.
- Waste container label includes isotope but not date, estimated activity, or responsible person.
- License amendment question handled informally without checking license conditions.

### 4. Mini decision trees

Add decision trees to existing pages and later convert the best ones into graphics.

Good topics:

- Do I apply to NRC or the state?
- Do I need a license amendment?
- Do I need a package receipt survey?
- Do I need dosimetry or bioassay?
- Can this waste be held for decay-in-storage?
- Do I need a shielding review or just an operational survey?

### 5. Records checklist tables

Add tables that map practical issues to records.

Suggested columns:

```text
Program area | Record to check | Why it matters | Common gap
```

Example rows:

- Surveys | Area survey logs | Confirms routine monitoring | Frequency does not match procedure.
- Instruments | Calibration certificate and check source log | Confirms defensible readings | Source checks not documented.
- Training | Initial and refresher training records | Confirms worker authorization | Site-specific topics missing.
- Waste | Decay-in-storage log | Supports disposal decisions | No final survey record.
- Package receipt | Receipt survey form | Supports DOT/license compliance | Label category or TI missing.

### 6. Author and reviewer credibility boxes

Add a short credibility note to technical pages.

Suggested format:

```text
Reviewed by: Board-certified health physicist / radiation safety professional.
Experience areas: radioactive materials licensing, RSO support, audits, inspections, radiopharmaceutical/R&D, medical, industrial, and academic programs.
Last updated: [Month Year].
Regulatory note: Requirements vary by license, jurisdiction, isotope, activity, facility design, and regulator.
```

### 7. Template previews on pages

Show part of each free resource directly on the page.

Examples:

- Package receipt checklist preview.
- Inspection binder table of contents.
- Radiation survey record preview.
- Decay-in-storage log preview.
- License amendment screening worksheet preview.
- RSO inspection readiness checklist preview.

### 8. Comparison tables

Comparison tables are strong AEO assets.

Good topics:

- NRC vs Agreement State.
- General license vs specific license.
- License amendment vs internal procedure change.
- Restricted area vs unrestricted area vs controlled area.
- Radiation survey vs contamination survey.
- Survey meter calibration vs source check.
- Sealed source vs unsealed radioactive material.
- RSO vs authorized user vs radiation worker.
- Package receipt survey vs routine area survey.
- Design shielding review vs operational survey.

### 9. Inspection binder architecture

Build a recurring section and future downloadable resource around a radioactive material inspection binder.

Recommended binder sections:

1. License and amendments.
2. RSO and authorized user approvals.
3. Training records.
4. Surveys and contamination records.
5. Instrument calibrations and source checks.
6. Package receipt records.
7. Waste and decay-in-storage records.
8. Dosimetry and bioassay records.
9. ALARA reviews.
10. Audits and corrective actions.
11. Security-related records, if applicable.
12. Decommissioning or area release records, if applicable.

### 10. Query harvesting workflow

Once Search Console is active, improve existing pages before creating new pages.

Monthly process:

1. Find queries with impressions but low clicks.
2. Improve title and meta description.
3. Add the exact question as an H2 if it fits naturally.
4. Add a direct answer block.
5. Add an FAQ answer.
6. Add internal links from related pages.
7. Create a standalone page only if the query has repeated impressions or high commercial value.

## Visual style guidance

Use a clean professional style appropriate for a technical consulting site:

- Minimal colors.
- Clear icons.
- No cartoon radiation hazards.
- Use the trefoil sparingly and professionally.
- Make text large enough for mobile.
- Include a text equivalent below each graphic.
- Use descriptive filenames and alt text.

Suggested filename pattern:

```text
/graphics/[topic]-[asset-type].png
```

Suggested alt text pattern:

```text
Infographic showing [process/concept] for [audience], including [main steps or elements].
```
