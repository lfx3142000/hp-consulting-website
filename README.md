# Advantage Health Physics Website

This repository contains planning, copy, SEO/AEO, forms, analytics, and future-funnel documentation for the Advantage Health Physics website.

## Current strategy

The site is currently a validation MVP.

The near-term purpose is to:

1. Publish useful health physics and radiation safety content.
2. Test organic search traffic and answer-engine visibility.
3. Collect demand signals through project inquiries, quote requests, submitted questions, free resource downloads, and email signups.
4. Learn which service categories and content clusters show interest.
5. Avoid building a full consulting operations stack until demand is clearer.

The site should not promise immediate response, emergency support, guaranteed consultations, or guaranteed acceptance of projects.

## MVP funnel

```text
SEO/AEO content
-> organic search traffic
-> request/project inquiry, submitted question, free resource download, or email signup
-> simple tracking sheet
-> monthly validation review
-> next content or service decision
```

## What to build first

1. Clean WordPress template artifacts and placeholder content.
2. Replace response-time promises with validation-safe request language.
3. Create or improve the Request a Quote / Project Inquiry page.
4. Create the Submit a Radiation Safety Question page.
5. Add privacy and disclaimer pages.
6. Set up Search Console, sitemap, and analytics.
7. Improve service pages with direct answers, FAQs, internal links, and CTAs.
8. Publish the first free resource: Radiation Safety Program Audit Checklist.
9. Build resources and topic hubs around high-intent SEO/AEO clusters.
10. Review metrics monthly before building operational infrastructure.

## What not to build yet

Do not build these until traffic and request data justify them:

- Client portal.
- Automated quote calculator.
- Payment workflow.
- Contract workflow.
- Complex CRM.
- Scheduling funnel.
- LMS or membership site.
- Paid ads.
- Cold email scraping.
- Custom web app.
