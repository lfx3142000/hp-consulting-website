# Website Implementation Guide

## Purpose

This guide explains how to carry out the website plan in a repeatable way. It is written for future website editors, writers, or automation-assisted drafting sessions.

1. `BUILD_PLAN.md`
2. `TASKS.md`

## Core rule

Keep the website in validation mode. The site should collect requests, questions, downloads, and email signups so the owner can evaluate demand. It should not promise a specific response time, guaranteed acceptance of work, or immediate service availability.

## Priority order

1. Clean visible WordPress placeholders and demo content.
2. Replace response-time promises with conservative request language.
3. Create the Request a Quote / Project Inquiry page.
4. Create the Submit a Question page.
5. Create privacy and disclaimer pages.
6. Set up search and analytics tracking.
7. Improve service pages.
8. Publish the first free resource.
9. Add internal links.
10. Create topic hubs.
11. Review monthly data before expanding operations.

## Page drafting checklist

Each page draft should include:

- Page title.
- Suggested slug.
- Meta title.
- Meta description.
- Primary query.
- Direct answer section.
- Practical explanation.
- FAQ section.
- Related internal links.
- Conversion action.
- Publication checklist.

## Service page checklist

Each service page should include:

- Who the page is for.
- Problems the service may help solve.
- Typical deliverables.
- Information a visitor should submit.
- Common mistakes.
- Related articles.
- Related free resource.
- Request/project inquiry CTA.

## Article checklist

Each article should include:

- A clear answer to one main question.
- Practical examples.
- A short FAQ section.
- Links to related service pages.
- Links to related resources.
- Submit-a-question CTA.

## Free resource checklist

Each free resource should include:

- Who it is for.
- What it helps with.
- Checklist or template content.
- General-use note.
- Download/signup CTA.
- Related service link.

## Validation-safe CTA

Use this style:

> Submit a project inquiry or quote request. We review submissions to understand current radiation safety needs and may follow up if the project appears to be a good fit.

## Validation-safe confirmation

Use this style:

> Thank you. Your submission has been received. We review submissions to understand current radiation safety needs and may follow up if the project appears to be a good fit. Submitting this form does not create a consulting relationship or guarantee of service.

## Monthly review

Each month, review Search Console, page traffic, downloads, questions, and inquiry categories. Build more content only around topics that show search impressions, clicks, downloads, submitted questions, or project inquiries.
