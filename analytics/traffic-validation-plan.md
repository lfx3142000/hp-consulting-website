# Traffic Validation Plan

## Purpose

The website MVP should measure whether health physics and radiation safety content attracts search traffic and produces useful demand signals.

The goal is not to optimize a complete consulting operation yet. The goal is to learn which topics, service areas, and visitor types show interest.

## Validation events

Track these events:

1. Quote request submission.
2. Project inquiry submission.
3. Submitted radiation safety question.
4. Free resource download.
5. Email update signup.
6. Contact form submission.
7. Click to email, if trackable.

## Minimum analytics setup

Use simple tools first:

1. Google Search Console.
2. Bing Webmaster Tools.
3. WordPress.com stats, Jetpack, GA4, Plausible, or another lightweight analytics option.
4. Manual lead tracking sheet.

Do not build a complex CRM during validation.

## Search Console setup checklist

1. Verify the site property.
2. Submit sitemap.
3. Inspect homepage URL.
4. Inspect top service page URLs.
5. Inspect top blog post URLs.
6. Check indexing status weekly for the first month.
7. Record top queries and pages monthly.

## 30-day validation threshold

After the first cleanup and tracking cycle, the site should aim for:

- 10+ indexed or submitted pages/posts.
- 100+ organic impressions.
- 3+ total conversion events.
- At least one topic cluster showing impressions.
- At least one form or freebie funnel working.

If these are not met, focus on indexing, page quality, internal links, and Search Console troubleshooting before adding many more pages.

## 90-day validation threshold

After 90 days, aim for:

- 25-40 useful pages/posts/resources live.
- 1,000+ organic impressions.
- 10+ total conversion events.
- 25+ free resource downloads or email signups.
- At least three measurable topic clusters.

If these are met, consider whether to respond more actively to leads, build deeper service pages, create paid products, or test targeted outreach.

## Decision rules

### Expand a topic when:

- It earns impressions.
- It earns clicks.
- It generates questions.
- It generates downloads.
- It generates inquiries.

### Improve a page when:

- It has impressions but low CTR.
- It has traffic but no conversion.
- It ranks for the wrong query.
- It lacks direct answer, FAQ, internal links, or CTA.

### Deprioritize a topic when:

- It gets no impressions after indexing.
- It has weak relevance to future services.
- It does not produce inquiries, questions, or downloads.
- It requires too much operational complexity for the MVP.

## Validation-safe follow-up decisions

For each submission, classify:

- Follow up now.
- Save for later.
- Use as content idea.
- Add to email list only, if consented.
- Ignore/spam.

The tracking system should support selective follow-up without requiring a full CRM.
